# Fondation Rebecca Nseya – Hope’s Care

Site vitrine statique (HTML, CSS, JavaScript), sans framework ni outil de build.

## Structure
```
index.html
style.css
script.js
assets/
  photo.jpg
  logo.svg
```

## Mettre en ligne avec GitHub Pages
1. Crée un dépôt GitHub et envoie tous les fichiers à la racine, en gardant le dossier `assets`.
2. Dans le dépôt : Settings → Pages → Source : « Deploy from a branch » → branche `main`, dossier `/ (root)`.
3. Après une minute, le site est disponible à l’adresse affichée sur cette page.

## Modifier
- Textes : `index.html`
- Couleurs et styles : variables en haut de `style.css`
- Photo : remplace `assets/photo.jpg` en gardant le même nom
